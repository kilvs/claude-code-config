# How {{NAME}} works

Applies to every org and client. Write your own rules here; Claude reads this file in every
session. Keep each rule short and say why when it is not obvious. Some prompts to start from:

- **Writing.** Tone, spelling (US or UK English), words or punctuation to avoid.
- **Files.** Where documents, assets and code live. Whether Claude may delete anything.
- **Push, deploy and publish.** Only on your explicit word, or freely on staging?
- **Client feedback.** Apply as asked, or push back first?
- **Scope.** Fix only what was asked, or tidy what is nearby?
- **Records.** Which files log a change (project `CLAUDE.md`, `BACKLOG.md`).
- **Verify.** How a change is checked before it is called done.
- **Commits.** Message style, identity, co-author line.
