# FiveM playbook (game dev)

**Status:** personal. Skills written Jun 2026; no client work.

## What it is used for
GTA V FiveM roleplay servers: Lua resources on Qbox and the ox stack, custom jobs, scripted
missions and events, NUI menus and HUDs, and securing resources against cheats. The detail
lives in the five skills, not here.

## Conventions
Whatever the skills say; they are the playbook. Server-authoritative by default (never trust
the client), one resource per feature, NUI in plain HTML/CSS/JS unless the skill says
otherwise. Record project-level decisions in the project's own `CLAUDE.md`.

## Accounts and tools
FXServer artifacts, txAdmin, Cfx.re keys, MySQL. Where the server and repos live: to be
recorded when the next project starts.
