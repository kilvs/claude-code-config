# PHP playbook

**Status:** learning, since 22 Sep 2026.

## What it is used for
The language under WordPress, and general server-side work. Learn it in two tracks: plain
modern PHP (8.x, Composer, PSR standards) first, then the WordPress dialect on top. Progress
goes in `learning.md`.

## Conventions
Default until a real project says otherwise:
- PHP 8.3 or newer, strict types on, Composer for dependencies, PSR-12 formatting via
  `php-cs-fixer` or `phpcs`.
- Small practice projects live in their own folder with their own README.
- Tests with PHPUnit or Pest from the first project.

## Accounts and tools
Local PHP via Homebrew (`brew install php composer`). Record the installed version here when
it is set up.
