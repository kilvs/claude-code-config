# Work

One folder per org: an agency, an employer, a studio, or `personal/`. Copy `_template/` to
`work/<org>/` to start one, then add the org to the table in `CLAUDE.md`.

- `README.md` is the org card: who, where code and docs live, which accounts.
- One file per client beside it (copy `_template/client.md`).
- `KICKOFF.md` is the prompt you paste into a fresh session for that org.

Cards stay short and point at the live state (the project's own `CLAUDE.md` "RESUME HERE"
block and its memory file). The state itself stays in the project. A stale line in a card is
a bug.
